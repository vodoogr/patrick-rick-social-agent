\# Patrick Rick Social Agent



AI-powered campaign system for automated social media publishing.



Core concept:

\- One active song campaign

\- Daily automatic content generation

\- Multi-day narrative rotation

\- Cinematic, non-generic content



Stack:

\- Next.js

\- TypeScript

\- Supabase



Modules:

\- Songs

\- Campaigns

\- Posts

\- Scheduler
